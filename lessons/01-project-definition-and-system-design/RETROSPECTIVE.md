## Delivery decisions

- Pre-session homework owns repository copying, dependency installation, FFmpeg, VoiceMode,
  and microphone permissions. These are machine-specific and must not consume room time.
- The fallback artifact is `resources/voice-command-card.md`. A student with a failed voice
  stack participates through typed Claude Code requests and records the failure for follow-up.
- Post-session work must remain ordered: Documentation Agent, DevOps Agent, roadmap, then
  commit/push. It depends on the architecture approved during the live session.

## Cut lines

Shorten the MCP transport comparison first, then the formatting-hook demonstration, then
the agent-registration tour. Never cut voice readiness, the rule-versus-enforcement
discussion, or the architecture review.
