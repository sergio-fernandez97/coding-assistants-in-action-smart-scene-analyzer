## Depth

**Roboflow does not store depth maps**, and this course does not store them elsewhere.
Depth is **inference-only**: Lesson 03 runs Depth Anything V2 and Lesson 04 serves its
output, but neither evaluates it against ground truth. See
`docs/decisions/` → *depth scope: inference only*.

| Field | Value |
|---|---|
| Source depth channel available? | `<yes — in the raw download, not retained here \| no>` |
| Depth ground truth in this dataset | **None** |
| Depth evaluation in Lesson 03 | **Qualitative and relative-ordering only** |

What that means downstream, stated here so nobody has to rediscover it:

- ✅ Supported: "the chair is nearer than the wall" — relative ordering
- ❌ Not supported: "the chair is 2.3 m away", and any depth error metric

Depth Anything V2 outputs **relative inverse depth** — larger means nearer, and the scale
is arbitrary. With no ground truth there is nothing to calibrate against, so the relative
units travel all the way to the API response. A field named `depth_meters` anywhere
downstream is a bug.

> If a later cohort wants quantitative depth, the raw channel is still in the SUN RGB-D
> download. Only the storage decision — S3, DVC, or GitHub Releases, plus an
> explicit image-ID-to-depth-map pairing — would have to be made.
